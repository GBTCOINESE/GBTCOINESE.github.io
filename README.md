# GBTCOINESE Website

Diese statische Website ist für das GitHub-Pages-Repository `GBTCOINESE.github.io` vorbereitet.

## Veröffentlichung

1. Den Inhalt dieses Ordners in das Stammverzeichnis des Repositorys hochladen.
2. Alle Originalbilder mit unveränderten Dateinamen in den Ordner `images` kopieren.
3. In GitHub unter **Settings → Pages** die Quelle **Deploy from a branch**, den Branch **main** und den Ordner **/(root)** auswählen.
4. Die Website ist anschließend unter https://gbtcoinese.github.io/ erreichbar.

## Struktur

- `index.html` – Startseite
- `about/` – Über uns
- `faq/` – 18 Fragen und Antworten
- `insights/` – Übersicht und zehn eigenständige Artikel
- `images/` – gemeinsamer Bilderordner
- `assets/` – Design und Navigation
- `sitemap.xml` und `robots.txt` – Suchmaschinen-Grundlagen
